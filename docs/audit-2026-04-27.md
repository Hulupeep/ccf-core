## Claim 1 - Canonical Update Form

Canonical audit formula:

```text
A_{t+1} = L_t * (A_t^(1-alpha) hadamard R^alpha) * C_t
```

Implementation excerpt:

```rust
pub fn positive_interaction(&mut self, recovery_speed: f32, tick: u64, alone: bool) {
    // Base delta scaled by personality, diminishing as value approaches 1.0
    let mut delta = 0.02 * (0.5 + recovery_speed) * (1.0 - self.value);
    if alone {
        delta *= 2.0; // Alone contexts bootstrap faster
    }
    self.value = (self.value + delta).min(1.0);
    self.interaction_count = self.interaction_count.saturating_add(1);
    self.last_interaction_tick = tick;
}
```

Evidence:

- `crates/mbot-core/src/coherence/mod.rs:459-467`
- `ccf-py/src/lib.rs:241-243` delegates Python `positive_interaction()` to
  this scalar accumulator path.

Verdict: FAIL.

Reason: implementation is a scalar accumulator update, not a matrix update. No
`L_t`, no `C_t`, no reference matrix `R`, no Hadamard product, and no matrix
exponentiation were found.

Falsifiability class: `other` - canonical matrix update absent.

## Claim 2 - The Min-Gate

Spec excerpt:

> **[0043]** The behavioral gating subsystem 130 computes an effective coherence value that governs the robot's behavioral output. The effective coherence is computed as the minimum of two values: an instantaneous coherence value and a context coherence value.

Implementation excerpt:

```rust
pub fn effective_coherence(&self, instant_coherence: f32, key: &ContextKey) -> f32 {
    let ctx = self.context_coherence(key);
    if ctx < 0.3 {
        // Unfamiliar: strict gate
        if instant_coherence < ctx {
            instant_coherence
        } else {
            ctx
        }
    } else {
        // Familiar: weighted blend -- history dampens noise
        (0.3 * instant_coherence + 0.7 * ctx).clamp(0.0, 1.0)
    }
}
```

Evidence:

- `crates/mbot-core/src/coherence/mod.rs:598-610`
- `ccf-py/src/lib.rs:273-274` exposes this function through Python.
- Pure Python fallback mirrors the same weighted blend at
  `ccf-py/python/ccf_core/coherence_field_py.py:55-65`.

Verdict: FAIL.

Reason: the implementation is hard `min` only when `ctx < 0.3`. For familiar
contexts, it uses weighted average `0.3 * instant + 0.7 * ctx`.

Falsifiability class: `other` - weighted-average substitution.
